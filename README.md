# 文创设计权利转换

把几天内压缩完成的创意征集 → 机器辅助设计 → 打样 → 销售授权全链路落到同一套服务上，
解决“来源说不清、学校作品被越界商用、同一元素被多个供应商拿去生产”的问题。

`domain.json` 是全部枚举的单一来源（贡献类型、用途范围、授权状态、版本类型、
样品状态、商品生产状态）。

## 两个核心结构

- **来源图（provenance）**：每个设计版本都记录父版本与所用素材；`provenance()`
  返回祖先版本与素材的传递闭包，任何最终商品都能一路追到原始贡献。
- **账目（ledger）**：生成回调、打样结论、授权更新、撤回争议、结算等全部状态变化
  都是追加式事件，带**幂等键**。重复回调、打样驳回重提、授权版本更新只回放首次结果，
  不产生重复版本/计数/分配。`verify_consistency()` 对账来源图与账目。

撤回与争议**不删除记录**，`impact_analysis()` 按生产状态分桶给出差异化处置：
尚未生产（暂停下单）、在制（暂停产线评估损失）、已售出/已完成（不追回、照约结算、后续停用）。

## 关键规则

1. **未成年人作品**：贡献者标记未成年；监护确认前素材 `监护就绪=false`，
   不能进入生成批次或版本合并，权属确认还有第二道监护校验（纵深防御）。
2. **用途逐项授权**：校内展示、公益展览、商品生产、渠道宣传分别授权。
   校园展示许可不会自动扩展为商业许可；素材缺某项有效授权时，授权版本的范围不能包含该项。
3. **商品生产授权**以样品验收通过为前提；驳回后可重提（轮次递增、历史保留）。
4. **权属确认**：贡献比例之和必须为 1，且与来源闭包中的贡献者精确对应
   （不漏分、不向无来源者分配）。
5. **授权版本更新**：版次递增，旧版标记“被替代”但永久保留；既有商品钉住原授权版次，
   新商品默认挂最新版，显式挂旧版被拒。
6. **供应商文件**：仅向订单所属供应商发放水印文件，限下载次数与到期日；
   非订单供应商返回 403，超限 429，过期 403。
7. **结算**：按最终确认的贡献比例分配（最后一人兜尾差，合计精确等于金额），
   钉住权属确认与授权版次，同一结算周期幂等。

## HTTP API（JSON，写接口接受 `幂等键`）

`POST`：`/briefs` `/contributors` `/guardian` `/contributions` `/grants`
`/batches` `/callbacks` `/versions` `/ownership` `/samples` `/sample-reviews`
`/licenses` `/suppliers` `/products` `/production` `/files` `/downloads`
`/settlements` `/withdraw` `/dispute`

`GET`：`/health` `/domain` `/events` `/verify` `/provenance/{版本}` `/impact/{贡献}`

## 运行

```bash
python3 service.py --check      # 检查枚举配置与初始一致性
python3 service.py --port 8000  # 启动服务
python3 -m unittest -v          # 24 个规则测试
```

当前为内存实现（单把锁串行化所有写操作，账目与来源图原子一致）；
`CreativeRightsService.snapshot()` 导出全部状态与事件，可作为持久化落点。
